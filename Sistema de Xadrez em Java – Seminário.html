Um jogo de xadrez completo no console: movimentos de todas as peças, xeque, xeque-mate, roque, en passant e promoção. Sem bibliotecas externas, sem game engines, sem frameworks: apenas as classes essenciais que já vêm no Java.

02Instanciação e inicialização

Ao fazer new ChessMatch(), o construtor cria um Board(8, 8), define turno 1, jogador WHITE e chama initialSetup(). Cada peça é criada com new e posicionada por placeNewPiece, que usa ChessPosition (ex.: a1) convertido para a matriz.

private void placeNewPiece(char column, int row, ChessPiece piece) {
    board.placePiece(new ChessPosition(column, row).toPosition(), piece);

03possibleMoves(): a matriz booleana

Cada peça implementa o método abstrato boolean[][] possibleMoves(). Ele devolve uma matriz 8×8 em que true marca as casas de destino (as azuis no console). Clique numa peça e depois numa casa azul para movê-la.

Nenhuma peça selecionada.

Simulação em JavaScript do mesmo raciocínio das classes Rook, Bishop, Queen, Knight, King e Pawn (sem roque e en passant).
